A bp (basis point) is 1/100th of a percent: 100bp = 1%, so 0.20% = 20bp. Round-trip cost is 2× fee + 2× slippage. If take-profit doesn't clearly beat that, the strategy loses money even when it's right. MEXC futures placed through the API cost 8bp per side — the 0%/0.01% shown in the MEXC app does not apply to API orders.
